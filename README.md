
📻 MiRadioApp
Aplicación de radio online desarrollada para Android.

🚀 Descripción
MiRadioApp permite escuchar diferentes estaciones de radio por Internet desde un dispositivo Android.

🛠️ Tecnologías utilizadas

Kotlin
Jetpack Compose
Android Studio
ViewModel
ExoPlayer
Coroutines
📱 Funcionalidades
📻 Lista de estaciones de radio
▶️ Reproducir radio online
⏸️ Pausar reproducción
🎵 Mini reproductor
🔄 Cambiar de estación
🏗️ Arquitectura

El proyecto está organizado utilizando una separación por capas para mantener el código ordenado y fácil de mantener.
